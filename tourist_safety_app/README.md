## 📌 Project Overview
PharmaGo is a mobile application designed to help customers quickly find medicines in nearby pharmacies, check real-time availability, compare prices, upload prescriptions, and place orders for delivery.  
Pharmacy owners can manage stock and confirm orders, delivery riders can update delivery status, and admins can monitor the system.

---

## 🚀 Key Features
- 🔍 **Medicine Search & Nearby Pharmacy Identification**: Real-time GPS-based pharmacy locator and medicine finder.
- 📦 **Real-Time Stock Updates**: Direct inventory synchronization from registered pharmacies.
- 📄 **Prescription Upload & Validation**: Secure prescription submission and pharmacy review.
- 🛒 **Order Placement & Notifications**: Instant checkout, status tracking, and automated customer alerts.
- 🚚 **Delivery Assignment & Live Tracking**: Rider allocation and transparent last-mile delivery tracking.
- 🛡️ **Admin Management**: System dashboard for managing users, handling customer complaints, and mitigating fake listings.

## 🛠️ Technology Stack

- **Backend & Database**: Firebase Authentication, Cloud Firestore, Firebase Storage
- **Location Services**: Google Maps Platform & Geolocation APIs
